Automated Novelty Assessment for Formalized Mathematics

What It Measures

AViD Journal is a novelty-assessment instrument. Current AI systems for mathematics measure correctness — they verify that a proof type-checks. AViD assumes correctness and measures novelty: is this theorem genuinely new, or has it been proven before?

Built on Lean 4 and the contemporary state of mathlib, AViD evaluates each theorem across three independent dimensions, applied in sequence:

  • D1 · EXISTENCE — Does this theorem already appear in formal libraries (mathlib, Leandex) or informal literature (arXiv, TheoremSearch)?
  • D2 · TRIVIALITY — Can standard tactics (decide, omega, simp, aesop) close the statement within a fixed budget?
  • D3 · PROOF DISTANCE — When the statement exists but proofs differ, Jaccard distance over the premises of the elaborated Lean 4 proof term measures structural novelty.

This is Ayrton's primary research project. A result that compiles is not the same as a result that is new.

> ./view --pipeline

  • 1. Ingestion Raw .tex file processing and metadata extraction via arXiv and TheoremSearch.
  • 2. Structural Parsing Semantic segmentation. Identifying boundaries of Definitions, Theorems, Lemmas, and Proofs. Currently utilizing the Claude API (claude-sonnet), though rule-based heuristic parsing is being explored for improvement and determinism.
  • 3. Formal Translation Neural-driven mapping. The Claude API is employed to translate natural language math into Lean 4 code.
  • 4. Formal Verification The generated code is checked by the Lean 4 prover. If the proof compiles, the theorem is marked as "Verified".
  • 5. Novelty Evaluation Cross-referencing against Mathlib and the broader mathematical literature along three axes: existence, non-triviality, and structural proof-distance.
  • 6. Publication Generation of verification metrics and formal validation reports for human reviewers. Results are stored in a SQLite database for traceability.
